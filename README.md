# MVP Серверного Решения для Анализа Текстовых Данных с ИИ 🚀

Этот проект представляет собой **Minimum Viable Product (MVP)** для масштабируемого серверного решения, предназначенного для хранения, обработки и анализа больших объемов текстовых данных. MVP интегрирован с моделью обработки естественного языка (LLM) для ответов на запросы пользователей. 🤖

## Описание 📄

MВП реализует ключевые функции, позволяющие загружать текстовые документы, выполнять по ним поиск и взаимодействовать с помощью ИИ. Он служит основой для будущего расширения до полнофункциональной системы с продвинутыми возможностями структурирования, фильтрации, генерации отчетов и поддержкой длинных контекстов через RAG. 🧠

**Особенности реализации:** ✨

*   **Работает локально:** Все компоненты (приложение, база данных, поисковый движок) могут быть запущены на локальной машине. 💻
*   **Оптимизирован для ограниченных ресурсов:** В текущей версии исключены тяжелые зависимости, что делает его пригодным для запуска на машинах с малым объемом оперативной памяти (вплоть до 2 ГБ). 🪶
*   **Гибкость ИИ:** Проект поддерживает интеграцию с различными LLM API. По умолчанию настроен на использование **Ollama**, что позволяет запускать ИИ локально **без автоматической загрузки тяжелых моделей**. Пользователь может самостоятельно выбрать и загрузить подходящую легковесную модель. Также поддерживается интеграция с платными облачными API (например, OpenAI) для потенциально более мощных моделей. 🌐

## Основные функции MVP 🌟

*   **Хранение данных:** 💾
    *   Загрузка файлов различных форматов (TXT, DOCX, PDF).
    *   Хранение файлов в локальной файловой системе.
    *   Хранение метаданных и извлеченного текста в базе данных SQLite.
*   **Обработка данных:** ⚙️
    *   Извлечение текста из загруженных файлов.
    *   Разбиение извлеченного текста на фрагменты (Chunking) для более точного поиска.
*   **Поиск и фильтрация:** 🔍
    *   Полнотекстовый поиск по содержимому документов и фрагментов с помощью Meilisearch.
    *   Базовая фильтрация результатов по типу файла.
*   **Интеграция с ИИ:** 🤖
    *   Взаимодействие с LLM через **Ollama** (локально, пользователь загружает модель самостоятельно) или облачные API (например, OpenAI).
    *   Поиск релевантных фрагментов документов для предоставления контекста ИИ.
    *   Генерация ответов на вопросы пользователей на основе найденного контекста.
*   **Веб-интерфейс:** 🖥️
    *   Простой веб-интерфейс для загрузки файлов, поиска и взаимодействия с ИИ.

## Архитектура 🏗️

*   **Backend:** Python, FastAPI
*   **Frontend:** HTML, JavaScript (встроенный в FastAPI)
*   **База данных:** SQLite
*   **Хранилище файлов:** Локальная файловая система
*   **Поиск:** Meilisearch (запускается как отдельный локальный процесс)
*   **ИИ:** Ollama (локально) или OpenAI API (облачно)

## Требования 📋

*   Python 3.8+
*   Meilisearch (установленный и запущенный как отдельный процесс)
*   Ollama (установленный и запущенный как отдельный процесс) **ИЛИ** Аккаунт и API-ключ для облачного LLM API (например, OpenAI)

## Установка и запуск ⚡

1.  **Клонируйте репозиторий:** 📥

    ```bash
    git clone <URL_вашего_репозитория>
    cd <название_папки_проекта>
    ```

2.  **Создайте виртуальное окружение и установите зависимости:** 🐍

    ```bash
    python -m venv venv
    # Активируйте venv (например, на Linux/Mac: source venv/bin/activate, на Windows: venv\Scripts\activate)
    pip install -r requirements.txt
    ```

3.  **Запустите Meilisearch:** 🔎

    *   Скачайте и установите Meilisearch с официального сайта: [https://www.meilisearch.com/docs/learn/getting_started/installation](https://www.meilisearch.com/docs/learn/getting_started/installation)
    *   Запустите исполняемый файл Meilisearch, указав мастер-ключ и путь к данным (замените `your_master_key_here` на надежный ключ):

        ```bash
        # На Windows (в cmd/PowerShell)
        meilisearch.exe --db-path ./meili_data --master-key=your_master_key_here

        # На Linux/macOS (в терминале)
        ./meilisearch --db-path ./meili_data --master-key=your_master_key_here
        ```

    *   Убедитесь, что Meilisearch запущен и доступен по адресу `http://localhost:7700`.

4.  **(Для использования Ollama) Запустите Ollama:** 🦙

    *   Скачайте и установите Ollama с официального сайта: [https://ollama.com/](https://ollama.com/)
    *   Запустите Ollama (обычно запускается автоматически как сервис или фоновый процесс после установки).
    *   **(Важно)** Пользователь самостоятельно **должен выбрать и загрузить** подходящую модель через команду `ollama run <имя_модели>`. Рекомендуются легковесные модели, такие как `phi3`, `gemma`, `tinyllama` и т.д., которые требуют меньше памяти. Проект **не загружает модель автоматически**. ⚠️

        ```bash
        # Пример загрузки легковесной модели (выполняется один раз)
        ollama run phi3
        ```

        Это скачает модель и запустит сессию взаимодействия в терминале. Для работы API этой сессии не нужна, можно закрыть терминал (`Ctrl+C`) после завершения скачивания.

5.  **Настройте переменные окружения:** ⚙️

    *   Создайте файл `.env` в корне проекта (рядом с `run.py`).
    *   **Для использования Ollama (по умолчанию):**

        ```env
        # Meilisearch
        MEILISEARCH_HOST=localhost
        MEILISEARCH_PORT=7700
        MEILISEARCH_MASTER_KEY=your_actual_meilisearch_master_key_here

        # Ollama
        OLLAMA_BASE_URL=http://localhost:11434
        OLLAMA_MODEL=phi3 # Замените на имя модели, которую вы самостоятельно загрузили
        ```

    *   **(Альтернатива) Для использования OpenAI API:**

        ```env
        # Meilisearch
        MEILISEARCH_HOST=localhost
        MEILISEARCH_PORT=7700
        MEILISEARCH_MASTER_KEY=your_actual_meilisearch_master_key_here

        # OpenAI
        LLM_API_KEY=your_openai_api_key_here
        LLM_MODEL=gpt-4o-mini
        LLM_BASE_URL=https://api.openai.com/v1
        ```

6.  **Запустите приложение:** ▶️

    ```bash
    python run.py
    ```

7.  **Откройте в браузере:** 🌐

    Перейдите по адресу `http://localhost:8000`.

## Использование 🧑‍💻

1.  Используйте форму на главной странице для загрузки текстовых документов (TXT, DOCX, PDF).
2.  Воспользуйтесь формой поиска для нахождения документов или фрагментов по ключевым словам.
3.  Используйте форму "Спросить ИИ", чтобы задать вопросы по содержимому загруженных документов. Система найдет релевантные фрагменты и передаст их в LLM (Ollama или облачную) для генерации ответа.
